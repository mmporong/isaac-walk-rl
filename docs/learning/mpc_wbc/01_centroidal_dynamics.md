# 01. Centroidal MPC 동역학을 처음부터 다시 보기

- 대응 원문: [Centroidal MPC 동역학 기초 - A·B·c 행렬, Skew, SO(3), Jacobian 연결](https://app.notion.com/p/Centroidal-MPC-A-B-c-Skew-SO-3-Jacobian-3cace2d5e06081a1b935d48be865b92a?pvs=25)
- 원문 대응 범위: 1~19절
- 학습 목표: `x`, `u`, `A`, `B`, `c`, `r×F`, `J^T F`를 하나의 물리 흐름으로 설명한다.

## 먼저 한 문장

사족보행 로봇의 몸통을 하나의 상자로 보고, 현재 몸통 상태와 네 발의 지면반력을 이용해 아주 짧은 시간 뒤의 몸통 상태를 계산한다.

```text
현재 몸 상태 + 네 발이 만든 힘 + 중력 = 잠시 뒤 몸 상태
```

이를 식으로 쓰면 다음과 같다.

```text
x[k+1] = A · x[k] + B · u[k] + c
```

지금은 행렬의 모든 숫자를 외우지 않는다. 각 항이 담당하는 물리만 잡는다.

## 1. Centroidal은 무엇을 단순화하는가

실제 로봇에는 몸통, 네 다리, 12개 관절이 있다. 처음부터 모든 부품의 운동을 동시에 계산하면 어렵다. Centroidal 모델은 우선 로봇의 전체 질량이 몸통 중심에 모여 있다고 보고 몸통의 이동과 회전에 집중한다.

- 보는 것: 몸통 위치·자세·선속도·각속도, 발의 지면반력
- 일단 생략하는 것: 다리 링크 각각의 자세와 관성, 모터 내부 동역학, 유연성
- 얻는 것: 미래 지면반력을 빠르게 최적화할 수 있는 작은 모델

따라서 이 모델은 유용한 근사이지 실제 로봇 전체와 동일한 모델은 아니다.

## 2. 상태 `x`: 지금 몸통이 어떤가

```text
x = [p, rpy, v, omega]    총 12개 숫자
```

| 상태 | 구성 | 뜻 | 대표 단위 |
|---|---|---|---|
| `p` | `[x,y,z]` | 몸통 중심 위치 | m |
| `rpy` | `[roll,pitch,yaw]` | 몸통 자세 | rad |
| `v` | `[v_x,v_y,v_z]` | 몸통 선속도 | m/s |
| `omega` | `[omega_x,omega_y,omega_z]` | 몸통 각속도 | rad/s |

각 묶음이 3개 숫자이므로 전체는 `3×4=12`차원이다.

## 3. 입력 `u`: 네 발이 몸통에 주는 힘

```text
u = [F_FL, F_FR, F_BL, F_BR]    총 12개 숫자
```

각 발의 힘은 `F_i=[F_x,F_y,F_z]`인 3차원 벡터다. 네 발이므로 입력도 12차원이다.

- `F_x`: 앞뒤 힘
- `F_y`: 좌우 힘
- `F_z`: 수직 힘

로봇이 바닥을 아래로 밀면 바닥은 로봇을 위로 민다. MPC가 구하는 `F_i`는 보통 로봇이 받는 지면반력 Ground Reaction Force, GRF다.

## 4. `A`: 현재 운동의 자연스러운 진행

아무 힘 변화가 없어도 현재 속도가 있으면 위치는 변한다.

```text
p[k+1] = p[k] + v[k] · dt
```

자세도 작은 각도 근사에서는 현재 각속도만큼 변한다고 설명할 수 있다.

```text
rpy[k+1] ≈ rpy[k] + omega[k] · dt
```

그래서 `A`는 다음을 담당한다.

> 현재 위치·자세·속도가 한 timestep 뒤로 자연스럽게 전달되는 규칙

`A`는 12×12 행렬이지만 3×3 블록으로 보면 `p←v`, `rpy←omega` 연결이 핵심이다.

### 주의

`rpy_next≈rpy+omega dt`는 쉬운 설명을 위한 강한 근사다. 원 논문은 작은 roll/pitch 조건에서 yaw에 따라 달라지는 변환을 사용한다. yaw가 0이 아닌 상황에서 두 표현을 같다고 가정하면 안 된다.

## 5. 힘이 만드는 두 가지 운동

발 하나의 힘 `F_i`는 몸통을 이동시키면서 동시에 회전시킨다.

### 병진 운동

뉴턴 법칙에서:

```text
m · dv/dt = 모든 발 힘의 합 + m · g
```

따라서 발 힘이 만드는 선가속도는 대략 다음과 같다.

```text
힘이 만드는 선가속도 = 모든 발 힘의 합 / 질량
```

같은 힘이라면 질량이 작은 로봇의 속도가 더 크게 변한다.

### 회전 운동

몸통 중심에서 발까지의 벡터를 `r_i`라 하면 발 힘이 만드는 토크는:

```text
발 i가 만드는 토크 = r_i × F_i
```

회전 가속도는 관성행렬 `I`를 사용해 다음처럼 근사한다.

```text
각가속도 = I⁻¹ · Σ(r_i × F_i)
```

즉 같은 위쪽 힘이라도 앞발과 뒷발, 왼발과 오른발은 몸통을 서로 다른 방향으로 회전시킨다.

## 6. Skew 행렬: 외적을 행렬곱으로 쓰기

벡터 `r=[r_x,r_y,r_z]^T`의 skew-symmetric matrix를 다음처럼 정의한다.

```text
        [  0    -r_z   r_y ]
[r]× =  [ r_z     0   -r_x ]
        [-r_y    r_x     0 ]
```

그러면 외적을 행렬곱으로 바꿀 수 있다.

```text
[r]× · F = r × F
```

MPC는 여러 발 힘을 하나의 큰 입력벡터로 묶어야 하므로 이 표현이 편리하다. Skew 행렬은 새로운 물리가 아니라 외적을 행렬 안에 넣는 표기법이다.

## 7. `B`: 발 힘이 다음 상태에 미치는 영향

발 `i` 하나의 3차원 힘이 12차원 상태에 주는 영향을 세로로 쌓으면:

```text
      [ (dt² / 2m) · I₃               ]  -> 위치 변화
B_i = [ (dt² / 2) · I⁻¹ · [r_i]×     ]  -> 자세 변화
      [ (dt / m) · I₃                 ]  -> 선속도 변화
      [ dt · I⁻¹ · [r_i]×             ]  -> 각속도 변화

B_i의 크기: 12행 × 3열
```

위에서부터 순서대로:

1. 힘이 위치를 바꾸는 양
2. 힘이 자세를 바꾸는 양
3. 힘이 선속도를 바꾸는 양
4. 힘이 각속도를 바꾸는 양

네 발의 블록을 옆으로 붙이면 전체 `B`가 된다.

```text
B = [B_FL  B_FR  B_BL  B_BR]    크기: 12행 × 12열
```

`B`의 숫자를 외우기보다 다음 두 효과만 기억한다.

```text
F/m                    -> 몸통 이동
I^{-1}(r cross F)      -> 몸통 회전
```

## 8. `c`: 항상 들어오는 중력

발 힘과 무관하게 중력은 매 timestep 작용한다. Notion의 12-state affine 표현에서는 중력을 `c`에 둔다.

```text
c = [0, 0, -0.5·g·dt²,    <- 위치 xyz
     0, 0,  0,             <- 자세 rpy
     0, 0, -g·dt,          <- 선속도 xyz
     0, 0,  0]             <- 각속도 xyz
```

즉 중력은 주로 다음 두 곳에 나타난다.

- z 위치: `-0.5 g dt^2`
- z 속도: `-g dt`

서 있을 때는 stance 발들의 위쪽 힘 합이 대략 무게와 같아야 한다.

```text
stance 발의 수직력 합 ≈ m · g
```

## 9. SO(3): 회전행렬이 사는 공간

3차원 회전행렬 `R`은 길이와 각도를 보존하며 다음 성질을 가진다.

```text
RᵀR = I,    det(R) = 1
```

이 조건을 만족하는 회전행렬의 집합을 `SO(3)`라고 부른다. 회전행렬을 시간에 따라 미분하면 `Rᵀ · dR/dt`는 skew-symmetric가 되고, 그 안의 세 숫자를 각속도 벡터와 연결할 수 있다.

처음 읽을 때는 다음 정도면 충분하다.

> `SO(3)`는 3차원 자세를 올바르게 표현하는 회전행렬의 공간이고, skew 행렬은 작은 회전과 각속도를 행렬로 연결한다.

## 10. Twist와 Screw: 이동과 회전을 한 벡터로 보기

강체의 순간 운동은 선속도와 각속도를 하나로 묶은 6차원 twist로 표현할 수 있다.

```text
twist V = [선속도 v, 각속도 omega]    총 6개 숫자
```

강체 운동은 어떤 축을 중심으로 회전하면서 그 축 방향으로 이동하는 screw motion으로 해석할 수 있다. 순수 직선 운동과 순수 회전은 그 특별한 경우다.

처음에는 screw의 모든 좌표식을 외울 필요가 없다. 다음 연결만 기억한다.

```text
각속도와 선속도를 합친 순간 운동 = twist
회전축과 축 방향 이동으로 강체 운동을 해석 = screw
관절 속도가 만드는 발의 twist = Jacobian으로 계산
```

## 11. Jacobian: 관절 움직임과 발 움직임의 연결

관절 속도 `q_dot`가 주어졌을 때 발의 Cartesian 속도는 Jacobian으로 연결된다.

```text
발 속도 = J(q) · 관절 속도
```

반대 방향으로, 발에 원하는 힘 `F`를 만들기 위한 관절 토크는 virtual work 관계에서 다음과 같다.

```text
관절 토크 = J(q)ᵀ · 발 힘
```

이것이 Centroidal MPC가 구한 stance 발 힘을 실제 다리 관절 명령으로 내리는 연결고리다. 힘의 좌표계가 world인지 body인지 확인하고 필요한 회전을 적용한 뒤 `J^T`를 곱해야 한다.

## 12. 전체 흐름

```text
현재 몸통 상태 x_k
  + 자연 진행 A x_k
  + 네 발 힘의 영향 B u_k
  + 중력 c
        |
        v
다음 몸통 상태 x_{k+1}

MPC가 stance 발 힘 F를 선택
        |
        v
좌표계 변환 -> tau = J^T F -> 관절 토크
```

## 확인 문제

1. 상태 `x`의 네 묶음과 전체 차원을 적어본다.
2. 입력 `u`가 왜 12차원인지 설명한다.
3. `A`, `B`, `c`를 각각 한 문장으로 설명한다.
4. 같은 위쪽 힘이 발 위치에 따라 다른 회전을 만드는 이유를 설명한다.
5. `[r]_x F`와 `r×F`의 관계를 적는다.
6. MPC가 구한 발 힘을 관절 토크로 바꾸는 식을 적는다.

### 최소 통과 기준

행렬의 모든 원소를 외우지 않아도 된다. 다음 세 문장을 자료 없이 말하면 첫 학습을 통과한 것으로 본다.

1. 발 힘의 합은 몸통의 선가속도를 만든다.
2. 몸통 중심에서 떨어진 발 힘은 `r×F` 토크를 만들어 회전시킨다.
3. stance 발의 원하는 힘은 좌표계를 맞춘 뒤 `J^T F`로 관절 토크에 연결한다.
